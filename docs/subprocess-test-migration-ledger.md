# Subprocess Test Migration Ledger

This ledger is the coverage contract for the evidence split authorised by the
[#177 resolution](https://github.com/secantdev/secant/issues/177#issuecomment-5755036178). It records every test file that reaches a real child at
`2d0142efc3f816820115a4dd4b9c6e3ab0b00ffb` before any test is rewritten or deleted. The issue #177 stress prototype remains branch-only evidence and
is deliberately excluded from this tree.

The target layers are **process-free semantic suite**, **standalone runtime conformance**, and **compiled-binary acceptance**. `open` means the old
subprocess-backed assertion still exists. Migrate rows independently: after a row's named replacement is green on Windows, macOS, and Linux, the
deletion change removes that old assertion and marks its row `done`. A whole file is deletable only when every one of its rows is `done`; rows remain
as historical coverage records after deletion.

The two Harness suites (`tests/harness/claude-code.test.ts`, `tests/harness/codex.test.ts`) also carried each Adapter's own cases — redaction, frame
parsing, authentication, discovery, argv, control, and qualification — beyond the shared conformance their first rows record. [#198](https://github.com/secantdev/secant/issues/198)
relocated those cases to `tests/harness/claude-code-adapter-conformance.ts` and `tests/harness/codex-adapter-conformance.ts`, registered into the standalone
runtime-conformance runner: every one drives the real Adapter (whose `prepare` spawns) or a scripted process a real child cannot emit on demand, so the
process-free semantic suite no longer spawns and parallel workers are restored. Their per-assertion rows are listed below.
